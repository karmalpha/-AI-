输入与 AI酒馆.html 同文件夹的 HTML 文件名
⚠️ 部分浏览器禁止 file:// 页面读取本地文件。若自动安装失败：① 先点「↗️ 打开该页面」确认 MOD 正常；② 复制 MOD 页面里的 JSON 数据；③ 粘贴到下方导入。

📘 MOD 编写指南

MOD 就是一个普通的 HTML 文件（放在 AI酒馆.html 同文件夹）。它只需定义一个全局对象 window.__MOD__，包含：systems（新规则系统 → 出现在车卡向导/团本编辑的系统列表）、adventures（预设团本/剧本 → 出现在团本列表）。

          
安装后：新规则出现在「车卡向导 → 卡种选择」与「团本编辑 → 规则系统」；MOD 预设团本出现在「团本·剧本」列表（卸载 MOD 会一并移除其团本）。

❓ 使用帮助

    

      快速上手：

      ① 创建角色卡（向导内含属性算法、法术自动选择、装备/宠物/物品填写）

      ② 选择预设团本/剧本（首页有快捷入口）

      ③ 进入跑团台，开始冒险！


      跑团台技巧：

      · 点击侧栏「敌人」→ 自动在输入框填入攻击指令；再点下方「武器/法术」chip 补全。

      · 骰子用 crypto.getRandomValues() 真随机，支持 d4~d100 与自定义 2d6+3。

      · 掷骰默认只在本地点数（可连掷多个），需要判定时点「📤 发送骰点给AI」；也可点「📤 自动发送」开启每次自动判定。

      · 鼠标悬停 AI 回复可：✏️ 修改 / 🗑 删除 / 🔄 重新生成。

      · 「📝 系统提示词」可查看并编辑发给 AI 的完整 System Prompt。

      · 世界书按关键词自动触发：提到某 NPC/地点时自动注入其设定。

      · 剧本杀模式：不需要角色卡；开始前先选角，然后按标准流程推进——DM引入 → 发本（每位玩家阅读自己的剧本原文并点「我已读完」）→ 讨论/搜证/质询循环 → 投票 → 真相复盘。

      · Galgame 模式：不需要角色卡（默认以「你」为主角），好感度实时显示，AI 给出选项，好感度决定结局。

      · 每轮对话自动保存；「完结本团」会播放庆祝动画并归档。

      · 跑团台输入框下方有 🎵 BGM 快捷切换（探索/战斗/休息/胜利 + 音量），设置页可上传自定义音频。

      · 想要自创内容？去「🧩 自定义生成」页：复制提示词给 AI，或用站内对话口生成，结果一键导入为团本/剧本/角色卡。


      没有 API Key？ 本地模式使用内置剧本预设回复，仍可体验全部 UI 与骰子。
