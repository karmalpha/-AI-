# 版本管理（versions）

本文件夹用于归档「AI酒馆·万界跑团台」的历史版本。**当前版本（最新）始终位于项目根目录的 `AI酒馆.html`**，发布新版本时把旧版本复制进这里再发布。

## 版本列表

| 版本 | 位置 | 说明 |
|---|---|---|
| **v2（当前）** | 根目录 `AI酒馆.html`（340KB 单文件） | 完整版：Markdown 渲染、13 风格×日夜、车卡向导（DND/COC/自定义+内置算法+法术自动过滤）、TRPG/剧本杀/Galgame 三种模式、5 个预设团本/剧本、世界书、可编辑系统提示词、可编辑/删除/重生成 AI 回复、真随机骰子（含自动/手动发送开关）、怪物图鉴（含 CR/XP）、资料库、BGM 合成器、存档系统、自定义生成助手（AI 按本站格式生成并一键导入）。本目录 `v2/` 存放该版本的构建资料（法术库/COC数据 JSON）与冒烟测试脚本。 |
| **v1（旧版雏形）** | `v1/AI酒馆.html`（113KB） | 最初的原型：仅基础角色卡/团本/对话/主题换色。已归档，仅供对比参考。 |

## 维护说明

- 单文件结构是**刻意保持**的：便于双击即用、单文件备份/分享、无需服务器。不建议拆分为多个 HTML（如需拆分，请把同一版本的多个文件放入 `versions/vX/` 文件夹统一管理）。
- 升级版本流程：① 把根目录 `AI酒馆.html` 复制到 `versions/vN/`；② 在根目录继续开发 vN+1；③ 更新本 README 的版本表。
- `versions/v2/_smoke_test.js` 是冒烟测试（Node 环境，`node _smoke_test.js`），用于回归验证 v2 的核心流程；它读取的是**根目录**的 `AI酒馆.html`。
- 数据说明：所有玩家数据（角色/团本/存档/设置）保存在浏览器 localStorage（键前缀 `tavern2_`），与 HTML 文件位置无关；**复制/移动文件夹不会带走数据**（数据在浏览器里）。v2 首次运行会自动迁移 v1（`tavern_` 前缀）的角色/团本/存档/API 设置；如需彻底清空，可在浏览器「清除站点数据」后重开。
