## 1. 属性生成算法（8 项属性）

COC 7th 的属性用 3d6 或 2d6+6 掷出，再 ×5 得到 3~99 的百分比数值。

| 属性 | 中文 | 英文 | 骰法 | 范围 |
|---|---|---|---|---|
| STR | 力量 | Strength | **3d6×5** | 15–90 |
| CON | 体质 | Constitution | **3d6×5** | 15–90 |
| SIZ | 体型 | Size | **2d6+6×5** | 40–90 |
| DEX | 敏捷 | Dexterity | **3d6×5** | 15–90 |
| APP | 外貌 | Appearance | **3d6×5** | 15–90 |
| INT | 智力 | Intelligence | **2d6+6×5** | 40–90 |
| POW | 意志 | Power | **3d6×5** | 15–90 |
| EDU | 教育 | Education | **2d6+6×5** | 40–90 |

### 衍生值公式（7 版要点，已核实）

| 衍生值 | 公式 | 说明 |
|---|---|---|
| HP 生命值 | **(CON+SIZ)/10，向下取整**（舍去小数，不是四舍五入） | 例：CON+SIZ=127 → HP=12 |
| MP 魔法值 | **= POW**（7 版改为 MP=POW，不再是 POW/5） | |
| SAN 理智 | **初始 = POW**（7 版 SAN=POW，不是 POW×5） | 上限 = 99 − 克苏鲁神话技能值 |
| Luck 幸运 | **3d6×5** | 每场游戏可重掷等，由守秘人裁定 |
| MOV 移动速度 | 见下 | |
| DB 伤害加值 | 依 STR+SIZ 查表 | 见下表 |
| Bld 体格 | 依 STR+SIZ 查表 | 与 DB 同表 |

**MOV 基础值**（比较 DEX、STR 与 SIZ）：
- DEX < SIZ 且 STR < SIZ → MOV 7
- 只有一项 ≥ SIZ → MOV 8
- DEX ≥ SIZ 且 STR ≥ SIZ → MOV 9
- 年龄修正：40–49 岁 −1，50–59 岁 −2，60–69 岁 −3，70–79 岁 −4，80+ 岁 −5（最低 1）

**DB / Bld 表**：

| STR+SIZ | DB | Bld |
|---|---|---|
| 2–64 | −2 | −2 |
| 65–84 | −1 | −1 |
| 85–124 | +0 | 0 |
| 125–164 | +1D4 | 1 |
| 165–204 | +1D6 | 2 |
| 205–284 | +2D6 | 3 |
| 285–364 | +3D6 | 4 |
| 365–444 | +4D6 | 5 |

### 年龄对属性的修正（7 版核心规则书 Step 7）

| 年龄 | 属性调整 |
|---|---|
| 15–19 | **STR −5，SIZ −5** |
| 20–39 | 无调整 |
| 40–49 | STR/CON/SIZ 三者中选一项 **−5**，**EDU +5** |
| 50–59 | STR/CON/SIZ 选一项 **−10**，**EDU +10** |
| 60–69 | STR/CON/SIZ 选一项 **−20**，**EDU +20** |
| 70+ | STR/CON/SIZ 选一项 **−40**，**EDU +40** |

> 注：EDU 随年龄增加体现阅历；所有属性上限 99。属性修正后再算 HP、DB 等衍生值。

## 3. 职业点与兴趣点（已核实）

- **职业技能点 = EDU × 2**（7 版统一为 EDU×2；旧版"不同职业不同倍率"的规则在 7 版已取消，所有职业倍率相同）。
- **兴趣点 = INT × 2**，可投入**任何**技能（不限职业技能表）。
- 点数直接加到技能基础值上；**车卡时单个技能最多投入 50 点**（职业点+兴趣点合计），且最终值不能超过 99。
- 信用评级必须在所选职业规定的范围内（用职业点购买），决定调查员的生活水平。

### 调查员创建流程（7 版）

1. **选择职业**（含该职业的信用评级范围）。
2. **投入职业技能点**（EDU×2）：只能投入该职业技能表列出的技能；信用评级须落在职业范围。
3. **投入兴趣点**（INT×2）：可投入任意技能（含职业技能表之外的）。
4. **计算衍生值**：HP、MP、SAN、Luck、MOV、DB、Bld（先做年龄修正）。
5. **背景**：姓名、年龄、外貌、故事、特质、装备等。

## 5. 理智规则（Sanity）

- **初始 SAN = POW**；**上限 = 99 − 克苏鲁神话**。检定 1D100 ≤ 当前 SAN 为成功；大失败（96–00）必失败。
- **SAN 损失**：遇恐怖/神话事件时，规则给出"成功/失败"两档损失（如 0/1D3、1/1D6）。检定成功损失小值，失败损失大值。
- **临时疯狂（Temporary Insanity）**：单次检定**失去 5 点及以上** SAN 触发，持续 **1D10 小时**；触发瞬间先进入一次疯狂发作。
- **不定疯狂（Indefinite Insanity）**：单次检定失去 **最大 SAN 的 20% 及以上** 触发，持续至接受治疗（通常需数周至数月游戏内时间）。
- **永久疯狂**：SAN 降至 0，调查员永久疯狂，角色交由守秘人接管。
- **疯狂发作表（Bout of Madness，1D10）**：1 失忆；2 心因性躯体症状（失明/失聪/瘫痪等）；3 暴力；4 偏执；5 重要之人依恋；6 昏厥；7 惊恐逃窜；8 歇斯底里/情绪爆发；9 恐惧症；10 狂躁症。发作持续 **1D10 战斗轮**。
- **恢复**：场景结束时做一次 SAN 检定，成功恢复 **1D3 SAN**（每场景限一次）；**精神分析**每次成功治疗恢复 1 点 SAN（需游戏内数周治疗期）；守秘人可因剧情表现授予 SAN 奖励。

## 6. 战斗规则要点

- **先攻**：每轮按 **DEX 从高到低**行动（7 版默认不掷先攻骰；同 DEX 协商或同时行动）。
- **行动**：每轮 1 个主要行动 + 反应动作（如闪避，每轮限 1 次）。
- **近战**：对抗检定（斗殴 vs 斗殴 或 斗殴 vs 闪避）；**闪避成功则本次攻击完全无效**。
- **检定层级**：普通成功 ≤ 技能；困难成功 ≤ 技能/2；极难成功 ≤ 技能/5；大成功 01；大失败 96–00（火器大失败会卡壳/走火）。
- **贯穿（Impale）**：极难成功且武器可贯穿 → 伤害 = 骰子最大值 + 再掷一次伤害骰，**忽略护甲**。
- **重伤（Major Wound）**：单次伤害 ≥ 最大 HP 的一半 → 需 **CON 检定**，失败昏迷；大失败可能死亡或永久伤残。
- **0 HP 及以下**：濒死。每轮 CON 检定：成功 → 稳定在 0 HP 昏迷；失败 → 再失 1 HP 继续濒死。急救/医学可稳定伤势。
- **护甲**：直接扣减伤害（如皮衣 1、凯夫拉 1D10 对枪弹）；贯穿无视护甲。
- **部位伤害（可选规则）**：1D20 → 1–3 右腿、4–6 左腿、7–10 腹部、11–15 胸部、16–17 右臂、18–19 左臂、20 头部；头部/胸部受重伤更易昏迷或致命（具体倍率由守秘人裁定）。
- **连射**：冲锋枪每轮可多次攻击（表内 1–4），自动连射命中数规则较复杂，建议查阅规则书「自动武器」一节。
